# Sicurezza

## Segnalare una vulnerabilità

Non aprire una *issue* pubblica: usa la segnalazione privata di GitHub
(scheda **Security** del repository → *Report a vulnerability*).

## Cosa sapere

NetworkToolkit cambia l'indirizzo MAC delle schede di rete, il che richiede permessi di amministratore: li chiede al sistema operativo nel modo normale. Lo speedtest contatta server pubblici di Cloudflare (`speed.cloudflare.com`).
